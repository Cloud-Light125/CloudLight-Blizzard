这些集合存在覆盖重叠，不能相加为“已验证功能数”，也没有建立 345 条运行断言到 763 条原声明的一一映射。**逐条业务实测覆盖率未确认，不能声称 763/763 业务执行通过。**

8 条 Presentation 断言分别验证：小窗口登录可见、Twitch 草稿保留、Twitch 保存 Click 命令路由、SOOP 草稿保留、YouTube 草稿保留、YouTube 频道快捷入口、SOOP 添加账号快捷入口、取消后在途授权不再重启。

UI/Host 另覆盖平台命令与只读真实 Worker 握手、Worker generation、停止取消、并发账号模拟、快照视觉树、绑定与 UI 线程。FeatureSelfTest 覆盖持久化、账号保护、区服预检/恢复、更新退出顺序、诊断脱敏；业务文件均在临时隔离目录中模拟。

生产页面仍连接原 ViewModel、Command 与事件。界面验收替身只通过显式命令行模式注入，不替换常规启动的数据源。真实第三方登录、奖励领取、Battle.net 恢复、游戏文件覆盖和 YouTube 登录按用户边界没有执行。
