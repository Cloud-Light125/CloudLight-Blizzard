## 调度与界面

- 保留 `selected_only`、官方指定主播优先规则、Drops 标记、账号绑定和限次活动资格门禁。分类号只规范化十进制前导零，继续拒绝名称模糊匹配。
- 智能模式按原优先级逐活动检查。离线、单个频道探测失败或分类搜索失败后继续检查其他已选活动。相同主播在一次检查中只探测一次，单批最多 8 个。失败与已确认离线分别计数。
- 离线等待约每 30 秒重查，任务刷新后按完成状态重新选台，纯队列配置变更唤醒现有账号调度。手动和赛事选台规则保留。冷却仅保留仍上线且持续满足当前任务规则的频道，分类频道同时重新核验场次和 Drops 标记。
- 每 UID 的 JSONL、日志和 WPF 展示等待原因、候选及在线频道数、活动和频道阶段计数。Worker 换代、停止或频道丢失后清理不适用的频道和诊断。隔离 WPF 测试用例只验证页面渲染与绑定。

安装候选保持 LOCAL-ONLY。SOOP Core 继续使用既有字节摘要基线，未修改第三方 Core 或创建公开发行版。
