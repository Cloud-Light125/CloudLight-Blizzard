之前提供的 patch 文件格式有误，@@ hunk 头缺少行号，所以 git 报：
patch with only garbage at ...:4

这份已修正为标准 unified diff，并已用 git apply --check / git apply 做过语法和应用测试。

使用：
1. 进入 Git 仓库根目录：
   git rev-parse --show-toplevel
   cd "<上一步显示的路径>"

2. 把两个 patch 放到仓库根目录后：
   git apply --check .\MainWindow.xaml.cs.patch
   git apply --check .\MainViewModel.cs.patch

3. 两个都无输出后：
   git apply .\MainWindow.xaml.cs.patch
   git apply .\MainViewModel.cs.patch

4. 检查：
   git diff -- Views/MainWindow.xaml.cs ViewModels/MainViewModel.cs

如果 --check 变成“patch does not apply”，说明你本地源码已经和 GitHub main 不同，不要强行 apply；把对应本地文件发给 ChatGPT 再基于本地版本生成。
