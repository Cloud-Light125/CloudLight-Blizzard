# CloudLight Blizzard

CloudLight Blizzard 是一款面向 Windows 的战网多账号与《守望先锋》实用工具。它将 Battle.net 多账号管理、账号与区服联动、守望先锋国服 / 国际服本地文件切换，以及战绩查询整理在同一个桌面应用中。

## 项目起源

CloudLight Blizzard 起源于开源项目 [qiyh99/BnetSwitch](https://github.com/qiyh99/BnetSwitch)，最开始，我只是打算在 BnetSwitch 的基础上移除与核心功能无关的内容（如展示广告、提交用户机器码等）并添加守望先锋国服/国际服文件切换功能后自己使用，而不上传仓库。

但实际修改过程中发现原有实现存在非常多的基础逻辑问题，修复范围很快超过了最初的预期。

后续处理的内容包括但不限于：
- Battle.net 账号备份与恢复逻辑
- 子目录未完整备份、恢复时的残留文件处理
- 登录状态判断
- 账号切换流程
- 深色模式
- UI 架构
- 数据存储
- 守望先锋国服 / 国际服文件切换
- 战绩页面
- 更新机制
- 以及其它大量稳定性和交互问题。

其中许多基础逻辑已经完全重构，部分功能也进行了新增或重新实现。

实际工作量已经接近甚至超过了重新开发一个新的软件！

当前的 CloudLight Blizzard 在程序架构、界面、数据管理、账号管理以及大量核心流程上，已经与最初的 BnetSwitch 存在明显差异，并且新增了国服 / 国际服文件切换功能，修复了大量的逻辑错误和安全隐患。因此，我决定开源此修改后的版本供更多的人使用。

尽管如此，仍然感谢原项目公开源码，使本项目能够从已有实现开始研究和继续开发。

## 主要功能

- 保存并管理多个 Battle.net 账号的本地状态
- 为账号设置自定义名称、备注和国服 / 国际服归属
- 切换账号时自动联动目标区服文件
- 使用本地文件快速恢复守望先锋国服或国际服版本
- 查询国际服公开生涯数据
- 在统一“掉宝”页面管理 SOOP、YouTube 与 Twitch Worker
- 共用全局 HTTP/HTTPS 代理、托盘生命周期、日志和 Documents 数据目录
- 支持深色模式、托盘运行和开机自动启动

## 掉宝与观赛整合

“掉宝”是单一一级导航，页面内切换 SOOP、YouTube 和 Twitch。三个平台的网络业务运行在独立无窗口 Worker 中，通过 UTF-8 JSON Lines 与 WPF 交换结构化状态；Worker 异常不会结束主程序，退出 CloudLight Blizzard 时会先请求 Worker 正常停止。

- SOOP：多账号 Session 隔离、自动/手动/仅 owesports 选台、优先任务、固定/抽奖/随机任务、背包、自动领取和低流量轮询设置。
- YouTube：Chrome/Brave 独立 Profile、自动频道/手动 URL、Headless、静音、播放恢复、实际观看时间与历史。Chrome DevTools 的 `127.0.0.1` 连接始终直连。
- Twitch：Device OAuth、cookies session、Campaign/Inventory/Channel、Priority/Exclude/PriorityMode、连接质量、通知、徽章表情、可用 Drop 检查和自动领取开关。

三个平台都提供“导入旧版数据”，执行 Copy → SHA-256 Verify，保留原目录；同名数据由用户选择跳过、覆盖或取消。

## Battle.net 多账号管理

CloudLight Blizzard 可以读取本机 Battle.net 的账号信息，并为多个账号保存各自的本地登录状态。已保存账号可以快速切换，每个账号都可以设置自定义名称、备注，以及国服或国际服归属。程序会自动识别当前账号，并同时展示所有已经保存的账号。

账号备份只包含 Battle.net 留在本机的必要配置状态，不保存或导出密码。账号卡片上的“更新账号备份”可在重新登录或本地状态变化后刷新备份。

## 守望先锋国服 / 国际服文件切换

区服文件功能的设计思路是：**使用本地磁盘空间换取网络流量**。

首次准备时，程序会按以下流程工作：

1. 保存当前区服的完整临时副本。
2. 让 Battle.net 只进行一次跨区更新。
3. 比较两个真实、完整的游戏版本。
4. 长期只保留国服和国际服之间真正不同的文件。

以后切换区服时，程序直接使用本地文件恢复目标区服，从而减少 Battle.net 反复下载相同区服差异文件。

程序不修改文件内部数据，不 patch 游戏二进制，也不会生成不存在的游戏文件；它只在本机已经通过 Battle.net 真实获得过的国服和国际服文件之间切换。

## 守望先锋战绩查询

“战绩”页面用于查询暴雪公开的国际服生涯数据。可以从国际服账号卡片进入并自动填入 BattleTag，也可以在页面中手动输入 `昵称#编号`。

页面展示公开的玩家资料、当前段位、表现概览和常用英雄；可在键鼠 / 手柄、快速 / 竞技分段间切换。查询结果取决于玩家是否公开生涯档案。

## 账号与区服联动

账号设置中的区服归属会参与账号切换流程。切换到国服账号时，程序会调用现有区服恢复流程切换到国服文件；切换到国际服账号时则恢复国际服文件。如果区服文件切换失败，Battle.net 的后续启动会停止，避免在错误文件状态下继续运行。

## 区服文件准备原理

准备阶段会建立两个完整版本的临时记录并比较相对路径、大小和内容摘要，最终生成可验证的本地区服差异备份。日常恢复只处理明确记录的差异文件，不修改未纳入管理范围的未知文件。

为保护已有数据，准备中的临时目录与当前可用备份分离；只有完整比较和写入成功后，新结果才会成为当前可用版本。

## 游戏更新以后如何重新准备

游戏更新可能改变公共游戏文件。程序检测到核心版本变化后，会把旧区服文件标记为需要重新准备，避免用旧文件覆盖新游戏版本。

此时请在“区服文件”页面重新执行准备流程：保存当前区服、让 Battle.net 完成一次跨区更新，再完成另一端文件比较。旧版本失效不代表账号备份失效，账号通常无需重新保存。

## 数据存储位置

默认数据根目录通过 Windows 的“文档”特殊目录获取，不硬编码用户路径：

```text
<MyDocuments>\CloudLight\CloudLight Blizzard
├─ settings.json
├─ accounts\
├─ logs\
├─ drops\
│  ├─ soop\
│  ├─ youtube\
│  └─ twitch\
├─ overwatch\
│  ├─ cache\
│  └─ session\
└─ region-switch\
   ├─ generations\
   ├─ staging\
   └─ active-generation.json
```

`region-switch` 可能占用较大空间。可以在“区服文件”页面将其设置到其它磁盘；已经配置的自定义存储位置会保持原位，不会被自动迁回文档目录。

升级时，程序会检查旧版本的数据目录。设置、账号、日志和战绩数据会安全复制到新目录并保留旧目录作为备份。旧默认区服目录会在可安全整体移动时迁到新默认位置；如果无法整体移动，则继续使用旧位置，避免复制几十 GB 数据。自定义区服目录不会被移动。

## 安装与运行

系统要求：

- Windows 10 或 Windows 11
- .NET 8 Desktop Runtime（框架依赖版本）
- 已安装 Battle.net；使用区服文件功能时需已安装《守望先锋》

## 基本使用方法

1. 启动 CloudLight Blizzard，在“账号”页面确认当前 Battle.net 账号。
2. 点击“更新账号备份”保存当前账号；登录其它账号后重复此步骤。
3. 编辑账号，为每个账号设置名称、备注和区服。
4. 在“区服文件”页面设置游戏位置和存储位置，并按提示完成一次双端准备。
5. 回到“账号”页面点击“切换”，程序会恢复账号状态并联动目标区服文件。
6. 在“战绩”页面选择任一已保存账号查看对应数据。

## 常见问题

### 程序会保存密码吗？

不会。程序不读取、导出或保存 Battle.net 密码。

### 为什么游戏更新后不能继续使用旧区服文件？

旧文件可能与新游戏版本不兼容。程序会阻止继续恢复，并要求重新准备，以避免覆盖更新后的游戏文件。

### 为什么区服准备需要较多临时空间？

首次准备需要保存当前完整版本，再与跨区后的完整版本比较。完成后只长期保留真正不同的文件，临时副本会被清理。

### 可以把区服备份放在其它磁盘吗？

可以。在“区服文件”页面更改“文件存储位置”。账号、设置和日志仍保存在文档目录，区服大文件使用你指定的位置。

### 国际服战绩没有内容怎么办？

确认 BattleTag 正确，并在游戏隐私设置中公开生涯档案。公开状态或服务网络异常也可能造成暂时无法查询。

## 数据安全说明

- 不保存 Battle.net 密码。
- 不修改游戏文件内部数据，也不 patch 游戏二进制。
- 账号恢复只处理明确纳入账号备份清单的本地配置文件。
- 区服恢复只处理已经比较、验证并记录的差异文件。
- 数据迁移先复制或整体移动，再检查关键内容并写入迁移标记；旧小型数据默认保留为一次性备份。
- 程序不会移动真实 Battle.net 安装目录、真实守望先锋游戏目录或用户自定义区服存储目录。
